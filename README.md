# 🖥️ Venkaiah Swamy Kalikaya — Portfolio

**B.Tech CSE · DSA · Web Development · AI**

[Live Site](https://venky-portfolio-v1.vercel.app)

Animated single-page portfolio built with **React, Vite, Tailwind CSS and Framer Motion**.

## 🚀 Quick Start

```bash
git clone https://github.com/Venky656/venky-portfolio.git
cd venky-portfolio
npm install
npm run dev
```

## 📜 Scripts

| Command           | Description          |
| ----------------- | -------------------- |
| `npm run dev`     | Dev server           |
| `npm run build`   | Production build     |
| `npm run preview` | Preview build        |
| `npm run lint`    | Lint                 |

## 📁 Structure

```
src/
├── components/              # UI components
└── data/portfolioData.js    # All personal content
```

Edit `src/data/portfolioData.js` to update bio, projects, skills and contact.
