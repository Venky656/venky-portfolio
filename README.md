## About

This is my personal portfolio — an interactive showcase of my journey as a Computer Science & Engineering student, from DSA problem-solving on LeetCode to building full web experiences. The site is built entirely by me: design, content, animations, and performance.

## Features

- **Cinematic hero** — spring-based entrance animations
- **Custom cursor** — interactive dot that reacts to interactive elements
- **Interactive projects showcase** — hover a project and its screenshot slides into the preview card
- **Copy-to-clipboard contact** — email, phone & address with instant toast feedback
- **Dark / light themes** with multiple accent colors
- **Lazy-loaded sections** and code-split bundles for fast loading

## Getting Started

```bash
# Clone the repository
git clone https://github.com/Venky656/venky-portfolio.git
cd venky-portfolio

# Install dependencies
npm install

# Start the development server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) to view it in the browser.

## Scripts

| Command           | Description              |
| ----------------- | ------------------------ |
| `npm run dev`     | Start dev server         |
| `npm run build`   | Production build         |
| `npm run preview` | Preview production build |
| `npm run lint`    | Run Oxlint               |

## Project Structure

```
venky-portfolio/
├── public/                  # Static assets (images, favicon)
├── src/
│   ├── components/          # UI components
│   ├── data/
│   │   └── portfolioData.js # All personal content
│   ├── App.jsx
│   └── main.jsx
└── vite.config.js
```

> **Tip:** Update your bio, education, skills, projects and contact details in `src/data/portfolioData.js` — no component changes needed.
